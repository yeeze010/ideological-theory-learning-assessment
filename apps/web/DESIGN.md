# 思政理论学习考核评价系统前端设计规范

## 设计方向

采用克制的 Swiss 信息系统风格：白色与浅灰作为工作底色，红色只用于主操作、当前导航和风险提示，依靠细边线与严格网格组织高密度教学管理信息。

## 视觉系统

- 主色：`#E4002B`
- 页面底色：`#F7F7F8`
- 正文：`#101216`
- 次要文字：`#68707C`
- 分隔线：`#D7DBE0`
- 字体：Helvetica Neue、Microsoft YaHei
- 圆角：业务面板保持直角，状态徽标仅使用小幅圆角
- 阴影：不使用装饰阴影，以边线区分层级

## 交互规则

- 未完成身份恢复前只显示身份核验状态，不渲染业务导航和数据。
- 所有角色、用户名和密码默认留空，登录失败在表单内说明。
- 主操作必须有后端接口；提交期间禁用按钮并显示进行状态。
- 401 清除会话并返回登录页；403 保留会话，在主界面显示权限提示。
- 列表统一提供读取中、空数据、失败和操作成功状态。
- 触控目标不小于 44px，键盘焦点始终可见。

## 角色入口

前端角色代码与共享契约保持一致：`platform_admin`、`org_admin`、`course_admin`、`question_admin`、`supervisor`、`learner`、`auditor`。导航只展示当前角色具备权限的功能，服务端继续承担最终授权判断。
