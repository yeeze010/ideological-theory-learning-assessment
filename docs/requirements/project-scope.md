# 项目定位与建设目标

## 项目概述

思政理论学习考核评价系统面向高校思政课程、主题教育、党团学习与校内理论学习活动，提供学习任务发布、课程章节学习、在线考试、阅卷评分、积分评价、统计分析、证书发放和学习报告生成的一体化平台。

## 建设目标

1. 建立覆盖学校、院系、班级、个人的学习考核闭环。
2. 支持课程章节、资料附件、视频课件、文档材料等多种学习资源管理。
3. 支持题库、组卷、在线考试、自动阅卷、人工阅卷与成绩复核。
4. 通过积分、排名、学习画像、证书和报告增强学习反馈。
5. 为管理员、教师和院系负责人提供个人、班级、院系统计报表。
6. 形成可审计、可部署、可扩展的工程骨架。

## 范围边界

MVP 范围包括组织用户、课程章节、学习任务、学习记录、题库、试卷、考试、阅卷、积分、证书、报表、通知、附件、审计日志。后续可扩展移动端、小程序、统一身份认证、AI 题目解析、智能学习推荐和数据驾驶舱。

## 技术栈建议

前端优先使用 Vue 3 + TypeScript + Vite + Pinia + Vue Router；后端建议使用 NestJS + TypeScript，便于前后端共享类型、DTO 和工程规范。数据库使用 PostgreSQL，缓存使用 Redis，文件存储使用 MinIO，部署使用 Docker Compose + Nginx。
