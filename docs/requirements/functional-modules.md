# 功能模块清单

| 模块 | 子功能 | 开发要点 | 验收要点 |
|---|---|---|---|
| 组织用户 | 学校、院系、专业、班级、账号、角色 | 支持批量导入、停用、重置密码 | 数据范围正确、导入错误可追踪 |
| 课程章节 | 课程、章节、课件、资料、完成规则 | 支持视频、文档、图文、外链、附件 | 章节顺序、必修/选修、完成条件有效 |
| 学习任务 | 发布对象、学习期限、任务进度、提醒 | 支持按院系、班级、学生定向发布 | 学生可领取，教师可查看进度 |
| 学习记录 | 浏览、时长、进度、测验、签到 | 防重复刷时长，记录设备/IP | 个人、班级、院系统计一致 |
| 题库 | 单选、多选、判断、填空、简答、材料题 | 分类、难度、标签、解析、审核 | 抽题准确，题目版本可追溯 |
| 组卷 | 固定卷、随机卷、策略组卷 | 按题型、难度、知识点配比 | 总分、题量、难度符合规则 |
| 在线考试 | 报名、开考、答题、交卷、防作弊 | 倒计时、断点续答、异常记录 | 并发、保存、交卷稳定 |
| 自动阅卷 | 客观题评分、填空匹配、规则判分 | 支持大小写、同义答案、部分分 | 分数准确，可复核 |
| 人工阅卷 | 主观题分配、评分、评语、复核 | 支持双评、仲裁、阅卷进度 | 阅卷记录完整，复核可回溯 |
| 积分评价 | 学习积分、考试积分、排名、等级 | 积分规则可配置，异常调整需审核 | 积分明细与总分一致 |
| 统计报表 | 个人、班级、院系、课程、考试 | 趋势、分布、完成率、通过率 | 可筛选、可导出、指标口径清晰 |
| 证书报告 | 证书模板、编号、学习报告、下载 | PDF 生成、防伪码、盖章图片 | 编号唯一，报告数据准确 |
| 通知告警 | 任务提醒、考试提醒、低完成率告警 | 站内信、邮件、短信预留 | 触发规则可配置 |
| 附件管理 | 上传、预览、下载、权限、水印 | MinIO 存储，病毒扫描预留 | 文件权限与业务对象一致 |
