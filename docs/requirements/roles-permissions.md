# 用户角色与权限矩阵

## 用户角色

| 角色 | 典型职责 | 数据范围 |
|---|---|---|
| 平台管理员 | 全局配置、组织管理、账号管理、审计、安全策略 | 全校 |
| 院系管理员 | 院系课程、班级、教师、学生、统计报表 | 本院系 |
| 班级管理员 | 班级成员、学习任务督促、班级统计 | 本班级 |
| 任课教师 | 课程章节、学习任务、题目、试卷、阅卷、成绩 | 所授课程和班级 |
| 题库管理员 | 题目分类、题目审核、题库质量 | 授权题库 |
| 阅卷教师 | 主观题阅卷、复核、评分意见 | 分配试卷 |
| 学生 | 学习、考试、查看积分、证书、学习报告 | 本人 |
| 审计员 | 查看操作日志、导出审计报表 | 授权范围 |

## 权限设计要点

采用 RBAC + 数据范围组合策略。所有写操作记录审计日志；跨院系访问必须经过授权；学生端只能访问本人数据；导出成绩、报告、证书需要二次权限校验和导出水印。
