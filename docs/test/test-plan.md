# 测试计划

## 测试策略

采用 gstack 式闭环：需求可追踪、用例可执行、缺陷可复现、验收可量化。测试覆盖单元测试、接口测试、集成测试、端到端测试、权限测试、性能测试、安全测试和验收测试。

## 核心测试用例表

| 编号 | 模块 | 场景 | 预期结果 |
|---|---|---|---|
| TC-001 | 学习任务 | 教师发布任务到指定班级 | 学生端可见，非目标学生不可见 |
| TC-002 | 课程章节 | 学生学习章节并达到完成条件 | 学习记录完成，任务进度更新 |
| TC-003 | 题库 | 导入题目含非法格式 | 导入失败项可下载，成功项入库 |
| TC-004 | 组卷 | 按难度和题型策略组卷 | 总分、题量、知识点比例正确 |
| TC-005 | 在线考试 | 答题中断后重新进入 | 已保存答案恢复，倒计时正确 |
| TC-006 | 自动阅卷 | 客观题交卷后判分 | 分数与标准答案一致 |
| TC-007 | 人工阅卷 | 主观题分配给阅卷教师 | 教师可评分，学生未阅前看到待阅 |
| TC-008 | 积分评价 | 完成任务和考试通过 | 积分明细生成且不重复 |
| TC-009 | 统计报表 | 查看班级与院系统计 | 指标与明细数据一致 |
| TC-010 | 证书报告 | 达成条件后生成证书和学习报告 | PDF 可下载，编号唯一 |
| TC-011 | 权限 | 学生访问管理 API | 返回 `PERMISSION_DENIED` |
| TC-012 | 文件附件 | 无权限用户下载附件 | 拒绝访问并记录审计 |

## 性能与稳定性

- 500 名学生同时考试，答题保存 P95 小于 500ms。
- 1000 条学习心跳/分钟写入无丢失。
- 10 万条学习记录报表查询 P95 小于 2s，必要时使用聚合表或缓存。
- 自动阅卷失败任务可重试，失败原因可追踪。

## 验收测试

每个里程碑结束输出测试报告、缺陷清单、截图证据和回归结论。上线前必须完成核心流程 E2E：发布学习任务、完成课程章节、参加考试、自动阅卷、人工阅卷、积分发放、统计报表、证书和学习报告生成。
