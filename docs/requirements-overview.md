# 需求总览

## 1. 建设目标

- 建立统一学习门户，覆盖课程学习、章节测验、正式考试、成绩查询、证书查看。
- 建立后台管理端，支撑组织、人员、课程、题库、考试、报表、通知、审计与系统配置。
- 建立从学习任务发布到成绩归档的闭环，确保数据可追溯、可导出、可验收。

## 2. 核心业务流程

1. 管理员创建课程、章节与学习资源。
2. 管理员维护题库、组卷规则和考试计划。
3. 学员按任务完成学习、测验与考试。
4. 系统自动评分，必要时进入人工复核。
5. 平台产出成绩、通过率、组织排名、题目分析与审计记录。
6. 项目组基于报表、日志与测试结果完成验收归档。

## 3. 角色清单

| 角色 | 主要职责 |
| --- | --- |
| 平台管理员 | 租户配置、全局参数、审计与平台级运维 |
| 组织管理员 | 组织架构、人员、角色、学习与考试任务发布 |
| 课程管理员 | 课程、章节、资源发布与审核 |
| 题库管理员 | 试题维护、导入导出、组卷规则 |
| 监学人员 | 学习进度与考试过程监督 |
| 学员 | 学习、答题、查成绩、查证书 |
| 审计人员 | 登录、操作、导出、成绩变更留痕检查 |
