# 验收标准与里程碑

## 验收标准

| 领域 | 验收标准 |
|---|---|
| 功能完整性 | 学习任务、课程章节、学习记录、题库、组卷、在线考试、自动阅卷、人工阅卷、积分评价、统计、证书、学习报告均可完成核心流程 |
| 权限正确性 | 不同角色只能访问授权菜单、按钮、接口和数据范围 |
| 数据一致性 | 学习记录、成绩、积分、报表、证书数据来源一致，可追溯 |
| 用户体验 | 学生端学习和考试流程顺畅，管理端表格、表单、看板清晰高效 |
| 性能稳定 | 满足并发考试、学习心跳、报表查询指标 |
| 安全审计 | 登录、导出、阅卷、积分调整、证书生成等关键操作留痕 |
| 部署运维 | Docker + Nginx 可一键部署，支持健康检查、备份、回滚 |
| 文档交付 | 需求、架构、设计、API、测试、部署、验收文档完整 |

## 开发里程碑

| 里程碑 | 周期 | 交付物 |
|---|---|---|
| M1 立项与工程骨架 | 第 1 周 | 仓库结构、技术栈、基础 CI、文档中心 |
| M2 组织权限与课程 | 第 2-3 周 | 用户角色、组织、课程章节、附件 |
| M3 学习任务与记录 | 第 4-5 周 | 任务发布、学习记录、进度统计、提醒 |
| M4 题库与组卷 | 第 6-7 周 | 题库、题目导入、固定/随机组卷 |
| M5 在线考试与阅卷 | 第 8-10 周 | 考试、自动阅卷、人工阅卷、成绩 |
| M6 积分报表证书 | 第 11-12 周 | 积分、个人/班级/院系统计、证书、学习报告 |
| M7 联调验收上线 | 第 13-14 周 | 测试报告、部署手册、验收材料、上线包 |

## 人员分工建议

| 角色 | 人数 | 工作内容 |
|---|---:|---|
| 项目经理/产品经理 | 1 | 需求管理、里程碑、验收协调 |
| 前端工程师 | 2 | 学生端、管理后台、报表、考试交互 |
| 后端工程师 | 2 | API、业务服务、权限、阅卷、证书 |
| 测试工程师 | 1 | 用例、接口、E2E、性能、安全测试 |
| UI/UX 设计师 | 1 | 页面规范、组件、交互、响应式 |
| DevOps | 0.5 | Docker、Nginx、CI/CD、监控备份 |

## 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 考试并发写入压力 | 交卷失败或答案丢失 | 自动保存、幂等提交、Redis 队列削峰、压测 |
| 权限范围复杂 | 数据越权 | RBAC + 数据范围统一中间件，权限测试覆盖 |
| 题库质量不稳定 | 考试公平性下降 | 题目审核、版本快照、错题率分析 |
| 阅卷延迟 | 成绩发布时间延后 | 阅卷任务分配、超期提醒、仲裁机制 |
| 报表口径争议 | 验收困难 | 指标字典前置确认，报表支持明细追溯 |
| 附件与证书存储异常 | 资源丢失 | MinIO 持久化、备份、上传重试、哈希校验 |
