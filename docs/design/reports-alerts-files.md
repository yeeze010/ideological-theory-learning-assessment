# 报表指标、告警通知与附件管理

## 报表指标

| 维度 | 指标 | 说明 |
|---|---|---|
| 个人统计 | 学习时长、任务完成率、章节完成数、考试通过率、积分、证书数 | 学生本人和授权教师可见 |
| 班级统计 | 班级完成率、平均分、通过率、未完成人数、积分分布 | 支持班级管理员和任课教师查看 |
| 院系统计 | 院系任务完成率、课程覆盖率、考试通过率、优秀率、风险班级 | 支持院系管理员查看 |
| 课程统计 | 章节访问量、平均学习时长、完成漏斗、资源下载量 | 用于优化课程内容 |
| 考试统计 | 最高分、最低分、平均分、题目正确率、主观题阅卷进度 | 支持成绩分析和题目质量分析 |

## 告警通知规则

| 场景 | 触发条件 | 接收人 | 处理建议 |
|---|---|---|---|
| 学习任务即将截止 | 截止前 72/24 小时未完成 | 学生、班级管理员 | 站内信提醒，可扩展短信 |
| 班级完成率偏低 | 截止前 24 小时完成率低于 70% | 班级管理员、教师 | 工作台告警 |
| 考试异常 | 切屏、超时、频繁断线、IP 异常 | 教师、考试管理员 | 标记考试记录，支持复核 |
| 阅卷超期 | 主观题超过设置时限未阅 | 阅卷教师、管理员 | 重新分配或催办 |
| 积分异常 | 单日积分超过阈值或重复来源 | 管理员 | 冻结积分调整，进入审核 |
| 证书生成失败 | PDF 生成或 MinIO 上传失败 | 平台管理员 | 自动重试并保留错误日志 |

## 文件附件管理

所有附件统一进入 `files` 表和 MinIO 对象存储。文件按业务对象绑定到课程、章节、题目、学习报告、证书、通知或导入任务。下载接口必须校验业务权限，不允许直接暴露永久公开地址。支持文件哈希去重、大小限制、类型白名单、预览地址短时签名、下载水印、导出审计和异常文件隔离。
