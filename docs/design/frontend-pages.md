# 前端页面清单与交互设计

## 视觉方向

采用克制、清晰、适合高校管理系统的 Swiss 管理后台风格：白色与中性灰为主，思政红作为强调色；布局强调表格密度、清晰层级、可扫描数据和稳定交互。字体使用系统中文字体，标题简洁，避免过度装饰。

## 学生端页面

| 页面 | 关键内容 | 交互要点 |
|---|---|---|
| 学习首页 | 待完成任务、考试提醒、积分、证书入口 | 优先展示下一步行动 |
| 学习任务列表 | 任务状态、截止时间、完成率 | 支持筛选未完成、即将截止 |
| 课程章节学习页 | 章节树、课件、附件、进度 | 自动保存进度，离开前提示 |
| 在线考试页 | 题目导航、倒计时、答题区 | 自动保存、断点恢复、异常提示 |
| 考试结果页 | 分数、解析、错题、积分 | 主观题未阅时显示待阅状态 |
| 个人统计页 | 学习时长、完成率、考试通过率、积分趋势 | 图表可切换周期 |
| 证书与报告页 | 证书下载、学习报告下载 | 展示编号、防伪码、生成时间 |

## 教师与管理后台页面

| 页面 | 关键内容 | 交互要点 |
|---|---|---|
| 工作台 | 待阅卷、低完成率告警、考试进行中 | 卡片进入具体处理页 |
| 组织用户管理 | 院系、班级、用户、角色 | 批量导入、错误回执 |
| 课程管理 | 课程、章节、资源、完成规则 | 章节拖拽排序、资源预览 |
| 学习任务管理 | 发布范围、截止时间、进度统计 | 发布前预览影响人数 |
| 题库管理 | 题目类型、难度、标签、审核状态 | 表单分步编辑，支持导入 |
| 组卷管理 | 固定卷、随机卷、策略配置 | 实时校验总分和题量 |
| 考试管理 | 考试设置、考生、监控、成绩 | 考试窗口和防作弊规则可配置 |
| 人工阅卷 | 主观题、评分框、评语、复核 | 键盘友好，评分自动保存 |
| 积分规则 | 规则、等级、调整申请 | 调整必须填写原因 |
| 报表中心 | 个人、班级、院系、课程、考试统计 | 支持筛选、导出、口径说明 |
| 附件中心 | 文件列表、归属对象、权限 | 预览、下载、替换、审计 |
| 系统设置 | 字典、通知模板、证书模板 | 模板变更记录版本 |

## 响应式与可用性

桌面端优先保证后台密集操作效率；平板端保持两栏布局；手机端以学生学习、考试和查看报告为主，管理端复杂表格降级为筛选 + 卡片列表。表单必须提供必填、格式、冲突、权限四类错误提示。
