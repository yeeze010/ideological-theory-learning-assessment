# 核心业务流程

## 学习任务流程

管理员或教师创建课程章节与学习任务，选择发布范围和完成条件。学生接收任务后进入课程章节学习，系统记录学习时长、进度、测验和附件查看行为。任务到期后生成个人、班级、院系统计，并触发未完成提醒。

## 考试评价流程

教师从题库选择固定组卷或策略组卷，发布考试并设置考试窗口、时长、次数、及格线和防作弊规则。学生进入考试后系统保存答题快照和异常记录。交卷后客观题自动阅卷，主观题进入人工阅卷；全部阅卷完成后汇总成绩、积分、排名、证书和学习报告。

## 闭环流程

学习任务 -> 学习记录 -> 在线考试 -> 自动阅卷 -> 人工阅卷 -> 积分评价 -> 报表统计 -> 证书/学习报告 -> 反馈改进。
