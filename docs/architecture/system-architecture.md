# 系统架构设计

## 总体架构

系统采用前后端分离架构。前端 `apps/web` 提供学生端、教师端、管理后台；后端 `apps/api` 提供 REST API、鉴权、业务服务、异步任务；`packages/shared` 沉淀 DTO、枚举、权限码和校验规则。

## 分层设计

| 层级 | 组件 | 职责 |
|---|---|---|
| 接入层 | Nginx、HTTPS、静态资源 | 域名接入、TLS、反向代理、缓存策略 |
| 前端层 | Vue 3、TypeScript、Vite | 页面、路由、状态、表单、报表、考试交互 |
| API 层 | NestJS、JWT、RBAC | REST 接口、权限校验、参数校验、审计 |
| 业务层 | 学习、课程、题库、考试、阅卷、积分、证书 | 核心业务规则与事务处理 |
| 数据层 | PostgreSQL、Redis、MinIO | 关系数据、缓存/队列、附件对象存储 |
| 运维层 | Docker、日志、监控、备份 | 环境交付、健康检查、数据保护 |

## 关键设计

- PostgreSQL 保存核心业务数据，考试提交和阅卷需要事务保证一致性。
- Redis 用于登录会话黑名单、考试倒计时状态、异步任务队列和热点报表缓存。
- MinIO 存储课件、附件、证书 PDF、学习报告 PDF，数据库只保存文件元数据与权限关系。
- 自动阅卷与证书生成建议使用队列异步执行，避免阻塞考试交卷接口。
- 所有管理端写操作记录审计日志，包含操作者、对象、动作、前后状态摘要、IP 和 User-Agent。
